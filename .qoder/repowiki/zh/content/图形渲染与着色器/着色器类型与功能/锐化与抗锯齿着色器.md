## 简介
本文档深入剖析了NextUI项目中用于提升复古游戏视觉效果的多种GLSL着色器。重点分析了`sharp-shimmerless.glsl`如何通过子像素级采样消除文本和UI元素的闪烁现象，`pixel_art_AA.glsl`针对像素艺术游戏设计的抗锯齿算法，`sharp-bilinear.glsl`在双线性插值基础上的锐化增强技术，以及`edge1pixel.glsl`用于强化像素边界清晰度的单像素边缘检测实现。同时，文档提供了各着色器在不同游戏类型中的启用建议，并说明了与像素化着色器的兼容性配置。

## 核心着色器分析

### sharp-shimmerless.glsl：消除闪烁的子像素采样
`sharp-shimmerless.glsl`着色器旨在为复古游戏提供最锐利的像素显示，同时消除走样和闪烁现象。其核心思想是将像素视为构成网格的理想矩形，而非点采样。它通过计算输入像素在输出像素上占据的表面积来进行插值。

**工作原理**：
1.  **顶点着色器**：计算输出像素坐标（`pixel`）、缩放比例（`scale`）和逆缩放比例（`invscale`）。
2.  **片段着色器**：
    *   确定当前输出像素的左上角（`pixel_tl`）和右下角（`pixel_br`）。
    *   计算这些角点对应的输入纹理像素（`texel_tl`, `texel_br`）。
    *   计算一个修正的采样点（`mod_texel`），该点考虑了输入和输出像素网格的对齐关系。
    *   使用修正后的坐标进行纹理采样，从而得到一个基于面积的、无闪烁的最终颜色。

此方法特别适用于高DPI屏幕，因为它能精确地处理非整数倍缩放，避免了传统方法在像素边缘移动时产生的闪烁。

**代码片段**：
```glsl
// 片段着色器中的核心计算
vec2 pixel_tl = floor(pixel);   
vec2 pixel_br = ceil(pixel);    
vec2 texel_tl = floor(invscale * pixel_tl);
vec2 texel_br = floor(invscale * pixel_br);

vec2 mod_texel = texel_br + vec2(0.5, 0.5);
mod_texel -= (vec2(1.0, 1.0) - step(texel_br, texel_tl)) * (scale * texel_br - pixel_tl);
    
FragColor = vec4(COMPAT_TEXTURE(Texture, mod_texel / TextureSize).rgb, 1.0);
```

### pixel_art_AA.glsl：像素艺术专用抗锯齿
`pixel_art_AA.glsl`是为像素艺术游戏设计的抗锯齿着色器，旨在解决传统抗锯齿导致图像模糊的问题。它通过检测特定的像素模式来智能地进行边缘平滑。

**工作原理**：
1.  **模式检测**：着色器以当前像素（E）为中心，采样其周围的8个邻近像素（A, B, C, D, F, G, H, I），形成一个3x3的网格。
2.  **亮度计算**：使用加权亮度公式 `lum(c) = dot(vec3(0.3,0.6,0.1), c)` 来判断像素的明暗。
3.  **条件判断**：通过一系列条件判断，识别出需要平滑的特定边缘模式。例如：
    *   **模式类型1**：当左侧（D）和上方（B）像素颜色相同，且与当前像素（E）不同时，如果当前像素更暗，则将其与左侧像素颜色混合。
    *   **模式类型2**：当当前像素（E）与下方（H）和右侧（F）像素颜色相同，且与左侧（D）不同时，如果当前像素更亮，则将其与左侧像素颜色混合。
4.  **颜色混合**：对于检测到的边缘像素，将其颜色与邻近像素的颜色进行简单的线性混合（`(E+D)/2.0`），以实现平滑过渡。

这种方法只在特定的、符合像素艺术美学的边缘上进行抗锯齿，从而保留了像素艺术的锐利感和清晰度。

### sharp-bilinear.glsl：预缩放锐化双线性插值
`sharp-bilinear.glsl`着色器在标准双线性插值的基础上，通过一个预缩放步骤来增强图像的锐度。

**工作原理**：
1.  **预缩放**：着色器首先将输入纹理按一个预设的倍数（`SHARP_BILINEAR_PRE_SCALE`）或自动计算的倍数（`AUTO_PRESCALE`）进行最近邻（Nearest-Neighbor）放大。这一步骤保留了原始像素的锐利边缘。
2.  **修正采样**：在进行最终的双线性插值时，着色器会计算一个“修正的纹理坐标”（`mod_texel`）。它通过分析当前采样点相对于其所在纹理像素中心的偏移量（`center_dist`），并根据预缩放因子（`scale`）对其进行调整。
3.  **硬件插值**：最终，使用修正后的坐标调用硬件的双线性插值功能，得到一个既锐利又平滑的结果。

其核心思想是，通过预缩放“欺骗”双线性插值，使其在更精细的网格上工作，从而减少了模糊感。

### edge1pixel.glsl：单像素边缘强化
`edge1pixel.glsl`着色器通过在相邻的源像素之间插入一条单像素宽的插值行来强化像素边界。

**工作原理**：
1.  **坐标判断**：着色器计算当前像素坐标的小数部分（`f`）。
2.  **区域划分**：定义一个 `INVERSE_SCALE_HALF` 值，用于判断当前像素是位于“源像素中心区域”还是“源像素边界区域”。
3.  **坐标映射**：
    *   如果像素位于中心区域（`isFractionInside.x` 为真），则将其映射到最近的源像素中心，以保持锐利。
    *   如果像素位于边界区域（`isFractionInside.x` 为假），则将其映射到两个源像素的正中间，以进行完美的线性插值。
4.  **结果**：这种处理方式在水平和垂直方向上都创建了清晰的单像素边界，强化了像素网格的视觉效果。

## 配置与兼容性

### 配置文件分析
项目中的`.cfg`文件定义了如何应用这些着色器。分析现有配置文件可以推断出最佳实践。

*   **pixelperfect-sharp.cfg**：此配置使用 `pixellate.glsl` 作为主着色器，并将缩放滤镜（`minarch_scale_filter`）设置为 `NEAREST`。这表明它追求纯粹的像素完美效果，与 `sharp-shimmerless.glsl` 的目标一致，但实现方式不同。`pixellate.glsl` 是一个基础的像素化着色器，通常作为其他效果的前置处理。

*   **pixelperfect-smooth.cfg**：此配置使用 `stock.glsl`（可能是默认或平滑着色器）并将缩放滤镜设置为 `LINEAR`，与 `sharp-sharp` 配置形成对比。

*   **real-gameboy.cfg**：此配置使用了两个着色器层：`pixellate.glsl` 用于像素化，`lcd3x.glsl` 用于模拟Game Boy的LCD屏幕效果。这说明 `pixellate.glsl` 可以作为基础层，与其他效果着色器（如锐化或抗锯齿）串联使用。

### 兼容性配置
虽然配置文件中没有直接引用 `sharp-shimmerless.glsl` 或 `pixel_art_AA.glsl`，但可以推断出它们的兼容性配置方式：
1.  **作为主着色器**：可以创建一个新的 `.cfg` 文件，将 `minarch_shader1` 设置为 `sharp-shimmerless.glsl` 或 `pixel_art_AA.glsl`，并设置 `minarch_scale_filter = NEAREST` 以获得最佳效果。
2.  **与像素化着色器串联**：`pixellate.glsl` 可以作为第一层（`minarch_shader1`），而 `sharp-shimmerless.glsl` 或 `pixel_art_AA.glsl` 作为第二层（`minarch_shader2`）进行后处理，以实现更复杂的效果。

## 应用场景与建议

| 着色器 | 适用游戏类型 | 启用建议 | 注意事项 |
| :--- | :--- | :--- | :--- |
| **sharp-shimmerless.glsl** | **平台跳跃、文字冒险、RPG** | 在高DPI屏幕上追求极致清晰度和无闪烁文本时使用。特别适合需要阅读大量文本的游戏。 | 在低分辨率屏幕上效果可能不明显。计算量略高于普通双线性插值。 |
| **pixel_art_AA.glsl** | **像素艺术平台游戏、动作游戏** | 当希望保留像素艺术的锐利感，同时平滑对角线和斜边时使用。适合角色轮廓清晰的游戏。 | 对于非像素艺术或高分辨率游戏，可能产生不自然的伪影。 |
| **sharp-bilinear.glsl** | **通用，特别是2D游戏** | 作为传统双线性插值的升级版，适用于大多数希望图像更锐利但又不完全像素化的场景。 | 预缩放倍数过高可能导致性能下降。 |
| **edge1pixel.glsl** | **复古风格、极简主义游戏** | 当希望强化像素网格的“数字感”和复古美学时使用。 | 可能使图像看起来过于“硬朗”，不适合追求柔和视觉效果的游戏。 |

**总体建议**：对于追求“像素完美”体验的用户，建议优先尝试 `sharp-shimmerless.glsl`。对于经典的像素艺术游戏，`pixel_art_AA.glsl` 能在清晰度和美观度之间取得良好平衡。`sharp-bilinear.glsl` 则是一个安全且有效的通用锐化方案。
