## 像素化着色器 (Pixellate)

像素化着色器通过模拟低分辨率像素网格来重现复古游戏的视觉风格。该着色器的核心算法在于计算输入像素在输出像素上的覆盖面积，并据此进行加权平均。

**视觉效果**：将图像分割成清晰的方形像素块，产生类似早期8位和16位游戏机的块状视觉效果。边缘呈现明显的阶梯状，强化了像素艺术的特征。

**适用游戏类型**：非常适合运行像素艺术风格的游戏，如经典平台游戏（超级马里奥）、角色扮演游戏（最终幻想）和动作冒险游戏（塞尔达传说）。

**性能开销**：性能开销较低，算法复杂度为O(1)，因为它只涉及固定数量的纹理采样和简单的数学运算。

**不同分辨率下的表现**：在高分辨率显示器上效果最佳，能清晰展现像素块的细节。在低分辨率下，像素块可能过大，导致图像细节丢失。

### 关键算法实现

```glsl
void main()
{
   vec2 texelSize = SourceSize.zw;

   // 计算当前像素在源纹理中的范围
   vec2 range = vec2(abs(InputSize.x / (outsize.x * SourceSize.x)), abs(InputSize.y / (outsize.y * SourceSize.y)));
   range = range / 2.0 * 0.999;

   float left   = vTexCoord.x - range.x;
   float top    = vTexCoord.y + range.y;
   float right  = vTexCoord.x + range.x;
   float bottom = vTexCoord.y - range.y;
   
   // 从四个角采样颜色
   vec3 topLeftColor     = COMPAT_TEXTURE(Source, (floor(vec2(left, top)     / texelSize) + 0.5) * texelSize).rgb;
   vec3 bottomRightColor = COMPAT_TEXTURE(Source, (floor(vec2(right, bottom) / texelSize) + 0.5) * texelSize).rgb;
   vec3 bottomLeftColor  = COMPAT_TEXTURE(Source, (floor(vec2(left, bottom)  / texelSize) + 0.5) * texelSize).rgb;
   vec3 topRightColor    = COMPAT_TEXTURE(Source, (floor(vec2(right, top)    / texelSize) + 0.5) * texelSize).rgb;

   // 计算边界位置
   vec2 border = clamp(floor((vTexCoord / texelSize) + vec2(0.5)) * texelSize, vec2(left, bottom), vec2(right, top));

   // 计算总面积
   float totalArea = 4.0 * range.x * range.y;

   // 根据各区域面积加权平均颜色
   vec3 averageColor;
   averageColor  = ((border.x - left)  * (top - border.y)    / totalArea) * topLeftColor;
   averageColor += ((right - border.x) * (border.y - bottom) / totalArea) * bottomRightColor;
   averageColor += ((border.x - left)  * (border.y - bottom) / totalArea) * bottomLeftColor;
   averageColor += ((right - border.x) * (top - border.y)    / totalArea) * topRightColor;

   FragColor = vec4(averageColor, 1.0);
} 
```

**中文算法说明**：
1.  **范围计算**：`range`变量确定了当前输出像素在源纹理中影响的区域大小。
2.  **角落采样**：从影响区域的四个角（左上、右下、左下、右上）进行纹理采样，获取四个角的原始颜色。
3.  **边界确定**：`border`变量计算了当前输出像素与源像素网格的交界线位置。
4.  **面积加权**：根据交界线将影响区域划分为四个子区域，计算每个子区域的面积，并以此为权重对四个角落的颜色进行加权平均，得到最终输出颜色。

## 扫描线着色器 (Scanline)

扫描线着色器通过模拟CRT显示器的扫描线效果，为图像添加明暗交替的水平条纹，营造出怀旧的电视观看体验。

**视觉效果**：在图像上叠加一系列水平的暗线，使画面看起来像是在老式CRT电视上播放。线条的明暗变化模拟了电子束扫描的亮度差异。

**适用游戏类型**：适用于所有复古风格的游戏，特别是那些最初在CRT电视上运行的游戏，如街机游戏、早期家用机游戏和电脑游戏。

**性能开销**：性能开销极低，主要计算是正弦函数，现代GPU可以高效处理。

**不同分辨率下的表现**：在垂直分辨率较高的显示器上，扫描线效果更细腻。在低分辨率下，扫描线可能过宽，影响画面清晰度。

### 关键算法实现

```glsl
void main()
{
    vec3 _scanline;
    _TMP0 = COMPAT_TEXTURE(Texture, TEX0.xy); // 获取原始颜色
    _x0009 = TEX0.xy*TEX2.xy; // 将纹理坐标映射到频率空间
    _TMP3 = sin(_x0009.x);
    _TMP4 = sin(_x0009.y);
    _TMP1 = vec2(_TMP3, _TMP4);
    _a0015 = vec2( 5.00000007E-02, 1.50000006E-01)*_TMP1; // 应用不同强度的调制
    _TMP2 = dot(_a0015, vec2( 1.00000000E+00, 1.00000000E+00)); // 计算总调制量
    _scanline = _TMP0.xyz*(9.49999988E-01 + _TMP2); // 将调制量应用到原始颜色上
    _ret_0 = vec4(_scanline.x, _scanline.y, _scanline.z, 1.00000000E+00);
    FragColor = _ret_0;
}
```

**中文算法说明**：
1.  **频率映射**：`TEX2.xy`在顶点着色器中被计算为 `(π * 输出宽度 * 纹理宽度 / 输入宽度, 2π * 纹理高度)`。这确保了在Y方向上，正弦函数的周期正好等于一个像素的高度。
2.  **正弦调制**：`sin(_x0009.y)` 生成一个在-1到1之间振荡的值，其周期与源纹理的像素高度对齐。
3.  **亮度调整**：将正弦值缩放后（`vec2(0.05, 0.15)`），与一个基础亮度（`0.95`）相加，得到一个在0.8到1.1之间变化的调制因子。
4.  **颜色应用**：将调制因子乘以原始颜色，使扫描线位置的颜色变暗（接近0.8倍），而线间位置的颜色接近正常或略亮。

## 复古效果着色器 (Retro-v2)

复古效果着色器 `retro-v2.glsl` 旨在模拟老式CRT显示器的色彩特性和非线性响应，为图像添加柔和的模糊和色彩混合效果。

**视觉效果**：图像边缘变得柔和，色彩出现轻微的“渗色”现象，整体色调偏暖，模拟了老式电视的荧光粉特性和电子束的扩散。

**适用游戏类型**：适用于需要营造强烈怀旧氛围的游戏，特别是那些色彩鲜艳的街机游戏和早期家用机游戏。

**性能开销**：性能开销中等，涉及多次幂运算和复杂的条件判断。

**不同分辨率下的表现**：在中等分辨率下效果最佳。在高分辨率下，其模糊效果可能不够明显；在低分辨率下，可能导致图像过度模糊。

### 关键算法实现

```glsl
void main()
{
    vec3 _E;
    vec2 _fp;
    vec2 _ps;
    vec2 _f;
    float _max_coord;
    vec3 _res;
    output_dummy _OUT;
    _TMP0 = COMPAT_TEXTURE(Texture, TEX0.xy);
    // 将颜色从sRGB转换到线性空间
    _TMP5 = pow(_TMP0.x, 2.40000010E+00);
    _TMP6 = pow(_TMP0.y, 2.40000010E+00);
    _TMP7 = pow(_TMP0.z, 2.40000010E+00);
    _E = vec3(_TMP5, _TMP6, _TMP7);
    
    _x0024 = TEX0.xy*TextureSize; // 将纹理坐标转换为像素坐标
    _fp = fract(_x0024); // 获取像素内的小数部分
    _ps = InputSize/OutputSize; // 计算缩放比例
    
    // 计算一个基于像素位置的衰减因子_f
    _x0026 = _fp + 5.00000000E-01*_ps;
    _TMP8 = min(vec2( 1.00000000E+00, 1.00000000E+00), _x0026);
    _TMP25 = max(vec2( 0.00000000E+00, 0.00000000E+00), _TMP8);
    _x0032 = _TMP25 - 8.39999974E-01;
    _TMP8 = min(_ps.xx, _x0032);
    _TMP31 = max(vec2( 0.00000000E+00, 0.00000000E+00), _TMP8);
    _f = _TMP31/_ps;
    _max_coord = max(_f.x, _f.y);
    
    // 基于衰减因子混合两种效果
    _a0040 = _E*(1.03999996E+00 + _fp.x*_fp.y); // 较亮的效果
    _b0040 = _E*3.60000014E-01; // 较暗的效果
    _res = _a0040 + _max_coord*(_b0040 - _a0040); // 线性插值
    
    // 将结果从线性空间转换回sRGB
    _TMP5 = pow(_res.x, 4.54545438E-01);
    _TMP6 = pow(_res.y, 4.54545438E-01);
    _TMP7 = pow(_res.z, 4.54545438E-01);
    _TMP3 = vec3(_TMP5, _TMP6, _TMP7);
    _TMP9 = min(vec3( 1.00000000E+00, 1.00000000E+00, 1.00000000E+00), _TMP3);
    _TMP49 = max(vec3( 0.00000000E+00, 0.00000000E+00, 0.00000000E+00), _TMP9);
    _OUT._color = vec4(_TMP49.x, _TMP49.y, _TMP49.z, 1.00000000E+00);
    FragColor = _OUT._color;
}
```

**中文算法说明**：
1.  **伽马校正**：首先将输入颜色从sRGB色彩空间（非线性）转换到线性色彩空间，以便进行物理上正确的计算。
2.  **位置衰减**：计算一个基于像素在纹理坐标中位置的衰减因子 `_max_coord`。这个因子在像素中心为0，在像素边缘接近1。
3.  **效果混合**：根据衰减因子，在两种处理后的颜色 `_a0040`（中心较亮）和 `_b0040`（整体变暗）之间进行线性插值。这导致像素中心比边缘更亮，模拟了CRT的“光晕”效果。
4.  **伽马还原**：最后将混合后的线性颜色转换回sRGB色彩空间进行输出。

## 像素艺术抗锯齿着色器 (Pixel Art AA)

像素艺术抗锯齿着色器专门设计用于消除像素艺术中因对角线或曲线产生的“锯齿”（jaggies），同时保持像素的锐利感。

**视觉效果**：平滑了斜线和曲线的边缘，使其看起来更柔和，但不会让整个图像变得模糊。它智能地只在需要的地方进行抗锯齿处理。

**适用游戏类型**：专为像素艺术游戏设计，特别是那些包含大量对角线运动或斜坡的游戏，如平台跳跃游戏和等距视角游戏。

**性能开销**：性能开销较高，因为它需要采样周围9个像素（3x3网格），并执行复杂的条件判断。

**不同分辨率下的表现**：在原始分辨率或整数倍缩放下效果最佳。在非整数倍缩放下，其效果可能不理想。

### 关键算法实现

```glsl
void main()
{
    vec2 pos = vTexCoord;
    float dx = SourceSize.z; // X方向的纹理步长
    float dy = SourceSize.w; // Y方向的纹理步长

    // 定义3x3邻域的9个像素
    vec3 A = COMPAT_TEXTURE(Source,vTexCoord + vec2(dx,-dy)).rgb;
    vec3 B = COMPAT_TEXTURE(Source,vTexCoord + vec2(0.0,-dy)).rgb;
    vec3 C = COMPAT_TEXTURE(Source,vTexCoord + vec2(-dx,-dy)).rgb;
    vec3 D = COMPAT_TEXTURE(Source,vTexCoord + vec2(dx,0.0)).rgb;
    vec3 E = COMPAT_TEXTURE(Source,vTexCoord).rgb; // 中心像素
    vec3 F = COMPAT_TEXTURE(Source,vTexCoord + vec2(-dx,0.0)).rgb;
    vec3 G = COMPAT_TEXTURE(Source,vTexCoord + vec2(dx,dy)).rgb;
    vec3 H = COMPAT_TEXTURE(Source,vTexCoord + vec2(0.0,dy)).rgb;
    vec3 I = COMPAT_TEXTURE(Source,vTexCoord + vec2(-dx,dy)).rgb;

    #define lumweight vec3(0.3,0.6,0.1)
    #define lum(c) dot(lumweight,c) // 计算感知亮度

    // 模式类型1: 检测锐角
    float L = (D == B && B == C && E != D && B !=A) ? 1.0 : 0.0;
    float R = (A == B && A == F && E != F && B !=C) ? 1.0 : 0.0;
    float DL = (D == H && D == I && E != D && H != G) ? 1.0 : 0.0;
    float DR = (F == G && F == H && E != F && H != I) ? 1.0 : 0.0;

    // 如果检测到锐角且中心像素较暗，则将其与相邻像素混合
    E = (L == 1.0 && lum(E)<lum(D) || DL == 1.0 && lum(E)<lum(D)) ? (E+D)/2.0 : E;
    E = (R == 1.0 && lum(E)<lum(F) || DR == 1.0 && lum(E)<lum(F)) ? (E+F)/2.0 : E;

    // 模式类型2: 检测钝角
    float GL = (E == H && E == F && E != D) ? 1.0 : 0.0;
    float GR = (E == D && E == H && E != F) ? 1.0 : 0.0;
    float GDL = (E == B && E == F && E != D) ? 1.0 : 0.0;
    float GDR = (E == D && E == B && E != F) ? 1.0 : 0.0;

    // 如果检测到钝角且中心像素较亮，则将其与相邻像素混合
    E = (GL == 1.0 && lum(E)>lum(D) || GDL == 1.0 && lum(E)>lum(D)) ? (E+D)/2.0 : E;
    E = (GR == 1.0 && lum(E)>lum(F) || GDR == 1.0 && lum(E)>lum(F)) ? (E+F)/2.0 : E;

    // 模式类型3: 检测其他斜角
    float SL  = (B == D && B == G && E != D) ? 1.0 : 0.0;
    float SR  = (B == F && B == I && E != F) ? 1.0 : 0.0;
    float SDL = (H == D && H == A && E != D) ? 1.0 : 0.0;
    float SDR = (H == F && H == C && E != F) ? 1.0 : 0.0;

    // 类似处理
    E = (SL == 1.0 && lum(E)<lum(D) || SDL == 1.0 && lum(E)<lum(D)) ? (E+D)/2.0 : E;
    E = (SR == 1.0 && lum(E)<lum(F) || SDR == 1.0 && lum(E)<lum(F)) ? (E+F)/2.0 : E;

    FragColor = vec4(E,1.0);
}
```

**中文算法说明**：
1.  **邻域采样**：着色器采样中心像素 `E` 周围的8个邻居，形成一个3x3的像素网格。
2.  **亮度计算**：使用 `lumweight` (0.3, 0.6, 0.1) 作为权重，计算每个像素的感知亮度，这更符合人眼对不同颜色的敏感度。
3.  **模式匹配**：通过一系列条件判断，检测中心像素周围是否存在特定的“锐角”、“钝角”或其他斜角模式。
4.  **智能混合**：一旦检测到某种模式，就根据中心像素与邻居的亮度关系，决定是否以及如何进行混合。例如，如果一个暗的中心像素位于一个亮的锐角内，它就会被部分提亮。

## 锐化着色器 (Sharp-Shimmerless)

锐化着色器旨在提供最清晰、最锐利的像素显示，同时消除在非整数倍缩放时常见的“闪烁”（shimmering）现象。

**视觉效果**：像素边缘极其清晰锐利，没有模糊或光晕。在动态画面中，像素不会出现抖动或闪烁，保持稳定。

**适用游戏类型**：适用于追求极致清晰度和稳定性的用户，特别是玩现代高清重制版或需要精确视觉判断的游戏。

**性能开销**：性能开销中等，涉及复杂的几何计算和浮点运算。

**不同分辨率下的表现**：在所有分辨率下都能提供稳定的锐利图像，特别擅长处理非整数倍缩放。

### 关键算法实现

```glsl
void main()
{
    // pixel: 输出屏幕像素
    // texel: 输入纹理像素 (游戏像素)
    vec2 pixel_tl = floor(pixel);   // 当前输出像素的左上角
    vec2 pixel_br = ceil(pixel);    // 当前输出像素的右下角
    vec2 texel_tl = floor(invscale * pixel_tl); // 左上角落在哪个源像素内
    vec2 texel_br = floor(invscale * pixel_br); // 右下角落在哪个源像素内

    // 计算采样点，以获得正确的盒式滤波值
    vec2 mod_texel = texel_br + vec2(0.5, 0.5);
    mod_texel -= (vec2(1.0, 1.0) - step(texel_br, texel_tl)) * (scale * texel_br - pixel_tl);
    
    FragColor = vec4(COMPAT_TEXTURE(Texture, mod_texel / TextureSize).rgb, 1.0);
} 
```

**中文算法说明**：
1.  **像素-纹素映射**：着色器将输出像素视为一个矩形区域，计算这个区域与源纹素（游戏像素）网格的交集。
2.  **交集分析**：通过 `pixel_tl` 和 `pixel_br` 确定输出像素的边界，再通过 `invscale`（输入/输出比例）将其映射回源纹理空间，找到覆盖的源像素。
3.  **精确采样**：算法计算一个精确的采样点 `mod_texel`，该点的位置考虑了输出像素相对于源像素网格的偏移。这确保了无论缩放比例如何，采样都基于正确的面积权重，从而消除了闪烁。

**节来源**
- [sharp-shimmerless.glsl](file://skeleton/BASE/Shaders/glsl/sharp-shimmerless.glsl#L1-L101)

## LCD模拟着色器 (LCD1x)

LCD模拟着色器用于模拟现代LCD屏幕的子像素结构和扫描线效果，为图像添加真实的液晶显示器质感。

**视觉效果**：在图像上叠加一个RGB子像素网格和水平扫描线，使画面看起来像是在真实的LCD屏幕上显示。颜色边缘可能出现轻微的彩色镶边。

**适用游戏类型**：适用于希望获得现代、清晰显示效果的用户，或者模拟Game Boy Advance等使用LCD屏幕的掌机。

**性能开销**：性能开销低，主要计算是正弦函数。

**不同分辨率下的表现**：在高PPI（每英寸像素数）的屏幕上效果最佳，能清晰展现子像素结构。

### 关键算法实现

```glsl
void main()
{
   // 生成LCD网格效果
   COMPAT_PRECISION vec2 angle =
      2.0 * PI * ((TEX0.xy * OrigInputSize * TextureSize / InputSize) - 0.25);

   // 计算X和Y方向的调制因子
   COMPAT_PRECISION float yfactor = (BRIGHTEN_SCANLINES + sin(angle.y)) / (BRIGHTEN_SCANLINES + 1.0);
   COMPAT_PRECISION float xfactor = (BRIGHTEN_LCD + sin(angle.x)) / (BRIGHTEN_LCD + 1.0);

   // 获取原始颜色样本
   COMPAT_PRECISION vec3 colour = COMPAT_TEXTURE(Texture, TEX0.xy).rgb;

   // 应用LCD网格效果
   colour.rgb = yfactor * xfactor * colour.rgb;

   FragColor = vec4(colour.rgb, 1.0);
} 
```

**中文算法说明**：
1.  **坐标映射**：`angle` 变量将纹理坐标映射到一个以2π为周期的正弦波空间。`-0.25` 的偏移确保了扫描线位于像素之间。
2.  **双轴调制**：在X方向（`angle.x`）上应用正弦调制来模拟RGB子像素的重复模式，在Y方向（`angle.y`）上应用正弦调制来模拟水平扫描线。
3.  **亮度控制**：`BRIGHTEN_SCANLINES` 和 `BRIGHTEN_LCD` 是可调参数，用于控制扫描线和子像素的亮度对比度。
4.  **效果叠加**：将两个调制因子相乘后，再乘以原始颜色，从而同时应用了子像素和扫描线效果。

## 水彩风格着色器 (Waterpaint)

水彩风格着色器是一种艺术化滤镜，它将图像渲染成类似水彩画的效果，具有柔和的边缘和扩散的色彩。

**视觉效果**：图像的轮廓变得柔和，颜色像水彩一样向外扩散和混合，产生一种梦幻般的、手绘的艺术效果。

**适用游戏类型**：适用于追求独特艺术风格的用户，或用于创造非传统的游戏视觉体验。

**性能开销**：性能开销较高，因为它需要采样多个纹理坐标并进行复杂的颜色混合计算。

**不同分辨率下的表现**：在中等分辨率下效果最佳。在高分辨率下，艺术效果可能过于细腻；在低分辨率下，可能显得过于模糊。

### 关键算法实现

```glsl
void main()
{
    vec3 _first;
    vec3 _second;
    vec3 _mid_horiz;
    vec3 _mid_vert;
    vec3 _res;
    vec3 _final;

    // 采样周围多个纹理坐标
    _TMP0 = texture2D(Texture, VARc00_01.xy);
    _TMP1 = texture2D(Texture, VARc00_01.zw);
    // ... (其他采样)

    // 在水平方向上进行线性插值
    _x0042 = VARc11.x*TextureSize.x + 5.00000000E-001;
    _TMP9 = fract(_x0042);
    _first = _TMP0.xyz + _TMP9*(_TMP6.xyz - _TMP0.xyz);

    // 在垂直方向上进行线性插值
    _x0054 = VARc11.y*TextureSize.y + 5.00000000E-001;
    _TMP12 = fract(_x0054);
    _mid_vert = _TMP3.xyz + _TMP12*(_TMP5.xyz - _TMP3.xyz);

    // 计算中心区域和边缘区域的差异
    _a0064 = _res - _TMP14;
    _TMP15 = abs(_a0064);

    // 进行非线性混合，增强边缘
    _final = 2.59999990E-001*(_res + _mid_horiz + _mid_vert) + 3.50000000E+000*_TMP15;

    // 应用阈值和钳制，形成水彩的“留白”效果
    _diff0066 = _final - vec3( 8.00000012E-001, 8.00000012E-001, 8.00000012E-001);
    _TMP17 = min(vec3( 1.00000000E+002, 1.00000000E+002, 1.00000000E+002), _diff0066);
    _TMP67 = max(vec3( 0.00000000E+000, 0.00000000E+000, 0.00000000E+000), _TMP17);
    _x0074 = _final - _TMP67*8.00000012E-001;

    FragColor = vec4(_x0074, 1.00000000E+000);
}
```

**中文算法说明**：
1.  **多点采样**：着色器在顶点着色器中预计算了多个偏移的纹理坐标（`VARc00_01`, `VARc02_10` 等），在片段着色器中对这些坐标进行采样。
2.  **双线性插值**：对采样的颜色进行水平和垂直方向的线性插值，得到 `_first`, `_second`, `_mid_horiz`, `_mid_vert` 等中间结果。
3.  **边缘增强**：通过计算中心区域与边缘区域的差异 `_a0064` 并取其绝对值，来识别图像的边缘。
4.  **非线性混合**：将平滑的插值结果与增强的边缘结果进行加权混合，形成水彩的笔触感。
5.  **留白效果**：通过减去一个阈值（`0.8`）并进行钳制，模拟水彩画中纸张的白色部分。

## 桶形失真着色器 (Barrel-Distortion)

桶形失真着色器通过几何变形来模拟老式CRT电视或鱼眼镜头的弯曲效果。

**视觉效果**：图像的边缘向内弯曲，中心向外凸出，形成一个“桶”的形状。这可以模拟老式电视的曲面屏幕。

**适用游戏类型**：适用于追求极致复古体验的用户，或用于创造特殊的视觉效果。

**性能开销**：性能开销低，主要计算是简单的算术运算。

**不同分辨率下的表现**：效果与分辨率无关，主要取决于失真强度参数。

### 关键算法实现

```glsl
void main()
{
    vec2 scale = TextureSize / InputSize;
    vec2 tex0 = TEX0 * scale; // 将纹理坐标映射到[0,1]的纹理空间
    vec2 texcoord = tex0 - vec2(0.5); // 将坐标原点移到中心
    float rsq = texcoord.x * texcoord.x + texcoord.y * texcoord.y; // 计算到中心距离的平方
    // 应用桶形失真公式: coord = coord + (coord * (k * r²))
    texcoord = texcoord + (texcoord * (BARREL_DISTORTION * rsq));
    texcoord *= rescale; // 重新缩放以补偿失真导致的图像缩小

    // 边界检查
    if (abs(texcoord.x) > 0.5 || abs(texcoord.y) > 0.5)
        gl_FragColor = vec4(0.0); // 失真区域外填充黑色
    else
    {
        texcoord += vec2(0.5); // 将坐标移回[0,1]范围
        texcoord /= scale; // 转换回纹理坐标
        vec3 colour = texture2D(Texture, texcoord).rgb;
        gl_FragColor = vec4(colour,1.0);
    }
}
```

**中文算法说明**：
1.  **坐标归一化**：将纹理坐标从[0,1]范围移动到[-0.5, 0.5]范围，使中心点位于(0,0)。
2.  **距离计算**：计算当前点到中心点的距离平方 `rsq`。
3.  **失真应用**：使用经典的桶形失真公式 `new_coord = old_coord * (1 + k * r²)`，其中 `k` 是失真系数。代码中将其拆解为 `coord + (coord * (k * r²))`。
4.  **重新缩放**：由于失真会使图像整体缩小，使用 `rescale` 因子（`1.0 - (0.25 * k)`）进行补偿。
5.  **边界处理**：检查失真后的坐标是否仍在有效范围内，超出范围的像素被设为黑色。

## 着色器组合与渲染链

NextUI支持通过配置文件将多个着色器串联起来，形成一个渲染链（Rendering Chain），每个着色器的输出作为下一个着色器的输入，从而实现复杂的效果叠加。

### 渲染链工作原理

系统通过 `minarch_nrofshaders` 参数定义渲染链中着色器的数量。每个着色器通道（Shader 1, Shader 2, Shader 3）可以独立配置：
- **着色器程序** (`minarch_shaderX`)：指定要加载的GLSL文件。
- **滤镜** (`minarch_shaderX_filter`)：选择纹理采样方式（NEAREST/锐利 或 LINEAR/平滑）。
- **源类型** (`minarch_shaderX_srctype`)：定义缩放的源分辨率。
- **纹理类型** (`minarch_shaderX_scaletype`)：定义纹理的分辨率类型。
- **缩放倍率** (`minarch_shaderX_upscale`)：定义图像的缩放倍数。

### 组合使用示例

#### 1. 真实Game Boy效果 (real-gameboy.cfg)
```ini
minarch_nrofshaders = 2
minarch_shader1 = pixellate.glsl
minarch_shader2 = lcd3x.glsl
```
**效果**：首先使用 `pixellate.glsl` 将游戏画面像素化，然后使用 `lcd3x.glsl`（或 `lcd1x.glsl`）在像素化后的图像上叠加LCD子像素网格和扫描线，完美模拟了Game Boy的绿色LCD屏幕。

#### 2. 复古电视效果 (old-tv.cfg)
```ini
minarch_nrofshaders = 2
minarch_shader1 = barrel-distortion.glsl
minarch_shader2 = res-independent-scanlines.glsl
```
**效果**：首先应用 `barrel-distortion.glsl` 为画面添加桶形弯曲，模拟CRT的曲面屏幕，然后使用 `res-independent-scanlines.glsl` 添加扫描线，营造出在老式电视机上玩游戏的怀旧氛围。

#### 3. 锐利像素效果 (pixelperfect-sharp.cfg)
```ini
minarch_nrofshaders = 1
minarch_shader1 = pixellate.glsl
```
**效果**：仅使用 `pixellate.glsl` 进行像素化，配合 `NEAREST` 滤镜，提供最原始、最锐利的像素显示，适合追求纯粹像素艺术美感的用户。

#### 4. 平滑像素效果 (pixelperfect-smooth.cfg)
```ini
minarch_nrofshaders = 1
minarch_shader1 = stock.glsl
minarch_shader1_filter = LINEAR
```
**效果**：使用 `stock.glsl`（一个简单的着色器）配合 `LINEAR` 滤镜，对像素进行平滑处理，适合不喜欢锐利像素边缘的用户。

### 决策指南

选择合适的着色器应考虑以下因素：

| 需求 | 推荐着色器 | 组合建议 |
| :--- | :--- | :--- |
| **追求极致复古** | `pixellate.glsl`, `scanline.glsl`, `barrel-distortion.glsl` | `pixellate` + `scanline` + `barrel-distortion` |
| **模拟特定硬件** | `lcd1x.glsl`, `retro-v2.glsl` | `pixellate` + `lcd1x` (模拟GBA) |
| **消除锯齿** | `pixel_art_AA.glsl` | `pixel_art_AA` (单独使用或放在链首) |
| **追求清晰锐利** | `sharp-shimmerless.glsl` | `sharp-shimmerless` (单独使用) |
| **艺术化风格** | `waterpaint.glsl` | `waterpaint` (单独使用) |
| **基础像素化** | `pixellate.glsl` | `pixellate` (单独使用) |

**可组合性**：大多数着色器可以组合使用。通常建议将几何变换类着色器（如 `barrel-distortion`）放在链的前端，将色彩处理类着色器（如 `lcd1x`, `retro-v2`）放在链的后端。抗锯齿着色器 `pixel_art_AA` 通常应作为第一个着色器应用，以确保后续处理基于平滑后的图像。
