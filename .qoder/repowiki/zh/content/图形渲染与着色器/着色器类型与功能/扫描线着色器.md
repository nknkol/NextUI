## 简介
扫描线着色器是一种用于模拟CRT显示器水平扫描线效果的图形渲染技术。通过在片段着色器中实现明暗交替的行渲染，该技术能够为复古游戏和街机模拟提供更加真实的视觉体验。本文档详细解析了`scanline.glsl`和`res-independent-scanlines.glsl`两个核心着色器文件的实现原理，探讨了其跨分辨率一致性的方法，并提供了适用于16-bit游戏和街机模拟的配置示例。

## 核心着色器分析

### scanline.glsl实现原理
`scanline.glsl`文件实现了基于片段着色器的明暗交替行渲染技术。该着色器通过计算每个像素的垂直位置对应的正弦值来控制扫描线的强度，从而模拟CRT显示器的扫描效果。

```glsl
// 片段着色器主函数
void main()
{
    vec3 _scanline;
    _TMP0 = COMPAT_TEXTURE(Texture, TEX0.xy);
    _x0009 = TEX0.xy*TEX2.xy;
    _TMP3 = sin(_x0009.x);
    _TMP4 = sin(_x0009.y);
    _TMP1 = vec2(_TMP3, _TMP4);
    _a0015 = vec2( 5.00000007E-02, 1.50000006E-01)*_TMP1;
    _TMP2 = dot(_a0015, vec2( 1.00000000E+00, 1.00000000E+00));
    _scanline = _TMP0.xyz*(9.49999988E-01 + _TMP2);
    _ret_0 = vec4(_scanline.x, _scanline.y, _scanline.z, 1.00000000E+00);
    FragColor = _ret_0;
    return;
}
```

该着色器在顶点着色器阶段计算了角频率`_omega`，然后在片段着色器中利用这个值与纹理坐标相乘，得到用于正弦计算的角度。通过正弦函数的周期性特性，实现了垂直方向上明暗交替的效果。

## 分辨率无关实现

### res-independent-scanlines.glsl的归一化方法
`res-independent-scanlines.glsl`着色器通过UV坐标归一化实现了跨分辨率的一致性。这种方法确保了在不同分辨率的设备上都能保持相同的视觉效果。

```glsl
float scale = imageSize; if (autoscale == 1.0) scale = InputSize.y; 
float angle = (gl_FragCoord.y * OutSize.w) * omega * scale + phase;
```

该着色器的关键创新在于使用`gl_FragCoord.y * OutSize.w`来归一化垂直坐标。`OutSize.w`是输出尺寸的倒数，这样可以将像素坐标转换为[0,1]范围内的归一化坐标。然后乘以角频率`omega`和缩放因子`scale`，得到最终的计算角度。

这种归一化方法的优势在于：
1. 与输出分辨率无关，确保在不同设备上的一致性
2. 可以通过`imageSize`参数精确控制模拟的图像高度
3. 支持自动缩放模式，根据输入尺寸动态调整

## 关键参数详解

### 扫描线强度参数(scanline_intensity)
在`res-independent-scanlines.glsl`中，扫描线强度主要通过`amp`（振幅）参数控制：

```glsl
#pragma parameter amp "Amplitude" 1.2500 0.000 2.000 0.05
```

`amp`参数控制正弦波的振幅，直接影响扫描线的对比度。值越大，明暗对比越强烈。该参数的取值范围为0.0到2.0，步进为0.05。

### 偶数行偏移参数(even_line_offset)
虽然在分析的文件中没有直接的`even_line_offset`参数，但通过`phase`参数可以实现类似效果：

```glsl
#pragma parameter phase "Phase" 0.5000 0.000 2.000 0.05
```

`phase`参数控制正弦波的相位偏移，可以用来调整扫描线的起始位置。通过调整相位，可以实现偶数行和奇数行的偏移效果，从而创建更复杂的扫描线模式。

其他重要参数包括：
- `lines_black`: 控制暗线的亮度
- `lines_white`: 控制亮线的亮度
- `imageSize`: 模拟的图像高度
- `autoscale`: 是否自动根据输入尺寸缩放

## 垂直方向模运算控制逻辑

### 基于正弦函数的模运算实现
扫描线着色器通过正弦函数的周期性特性实现了垂直方向的模运算控制。以下是`res-independent-scanlines.glsl`中的核心逻辑：

```glsl
float lines;
lines = sin(angle);
lines *= amp;
lines += offset;
lines = abs(lines);
lines *= lines_white - lines_black;
lines += lines_black;
color *= lines;
```

这个过程可以分解为：
1. 计算正弦值：`sin(angle)`产生[-1,1]范围的周期性输出
2. 应用振幅：`lines *= amp`调整波动范围
3. 添加偏移：`lines += offset`将范围移动到[0,2]
4. 取绝对值：`abs(lines)`创建对称的波形，实现交替的明暗效果
5. 映射到目标范围：通过线性变换将值映射到`lines_black`到`lines_white`之间
6. 应用到颜色：`color *= lines`将扫描线效果应用到原始颜色

这种基于正弦函数的实现方法比传统的模运算更加平滑，避免了硬边缘的出现，更接近真实CRT显示器的效果。

## 性能表现与VSync协同优化

### 高刷新率设备上的性能表现
扫描线着色器在高刷新率设备上的性能表现主要取决于以下几个因素：
1. 着色器复杂度：`res-independent-scanlines.glsl`非常轻量，只包含基本的数学运算
2. GPU处理能力：现代GPU可以高效处理这种简单的片段着色器
3. 内存带宽：主要开销在于纹理采样和帧缓冲读写

由于扫描线着色器的计算复杂度很低，即使在高刷新率设备上也能保持良好的性能表现。

### 与垂直同步（VSync）的协同优化策略
系统通过以下方式实现扫描线着色器与VSync的协同优化：

```c
// api.c中的VSync同步函数
void GFX_sync_fixed_rate(double target_fps) {
    if (target_fps == 0.0) target_fps = SCREEN_FPS;
    int frame_budget = (int) lrint(1000.0 / target_fps);
    uint32_t frame_duration = SDL_GetTicks() - frame_start;
    if (gfx.vsync!=VSYNC_OFF) {
        if (gfx.vsync==VSYNC_STRICT || frame_start==0 || frame_duration<frame_budget) {
            PLAT_vsync(frame_budget-frame_duration);
        }
    }
    else {
        if (frame_duration<frame_budget) SDL_Delay(frame_budget-frame_duration);
    }
}
```

```c
// platform.c中的底层VSync实现
void PLAT_vsync(int remaining) {
    if (remaining>0) SDL_Delay(remaining);
}
```

协同优化策略包括：
1. **帧预算控制**：根据目标帧率计算每帧的时间预算
2. **动态延迟**：在帧处理时间不足时，使用`SDL_Delay`进行精确延迟
3. **VSync模式选择**：支持多种VSync模式，包括关闭、严格同步等
4. **性能监控**：通过`frame_duration`监控实际帧处理时间

这种协同优化确保了扫描线动画的流畅性，避免了画面撕裂，同时最大限度地利用了GPU的处理能力。

对于16-bit游戏如SFC或MD的模拟，推荐使用以下配置：

```cfg
minarch_nrofshaders = 2
minarch_shader1 = pixellate.glsl
minarch_shader1_filter = NEAREST
minarch_shader1_srctype = source
minarch_shader1_scaletype = source
minarch_shader1_upscale = screen
```
