## 项目结构

NextUI的图形渲染系统主要由两大部分组成：**BASE** 和 **SYSTEM** 目录下的着色器文件。这些文件通过 `.cfg` 配置文件进行管理和应用。

```mermaid

end
```

## 核心组件

NextUI的图形渲染系统包含以下核心组件：

- **GLSL着色器文件**：实现各种视觉效果，如像素化、扫描线等。
- **.cfg配置文件**：定义着色器链和渲染参数。
- **渲染引擎**：加载并执行着色器链，处理图形输出。

这些组件协同工作，为模拟器提供丰富的视觉体验。

## 详细组件分析

### 内置着色器分析

#### 像素化着色器 (pixellate.glsl)
该着色器通过计算像素区域的平均颜色来实现像素化效果。

```mermaid
flowchart TD
Start[开始] --> GetTexelSize["获取纹理像素大小 (texelSize)"]
GetTexelSize --> CalculateRange["计算采样范围"]
CalculateRange --> SampleCorners["对四个角落进行纹理采样"]
SampleCorners --> CheckGamma["检查线性伽马插值"]
CheckGamma --> |开启| ApplyGamma["对采样颜色应用伽马校正"]
CheckGamma --> |关闭| SkipGamma["跳过伽马校正"]
ApplyGamma --> Interpolate["计算加权平均颜色"]
SkipGamma --> Interpolate
Interpolate --> ApplyInverseGamma["应用逆伽马校正"]
ApplyInverseGamma --> Output["输出最终颜色"]
```

**图源**
- [pixellate.glsl](file://skeleton/BASE/Shaders/glsl/pixellate.glsl#L50-L100)

#### 扫描线着色器 (scanline.glsl)
该着色器通过正弦函数调制亮度来模拟CRT显示器的扫描线效果。

```mermaid
classDiagram
class ScanlineShader {
+vec4 _TMP0 : 采样颜色
+vec2 _x0009 : 纹理坐标乘以频率
+float _TMP3 : x方向正弦值
+float _TMP4 : y方向正弦值
+vec2 _TMP1 : 正弦值向量
+vec2 _a0015 : 调制幅度
+float _TMP2 : 点积结果
+vec3 _scanline : 最终扫描线颜色
}
ScanlineShader : void main()
ScanlineShader : COMPAT_TEXTURE(Texture, TEX0.xy) 获取原始颜色
ScanlineShader : sin(_x0009.x) 计算x方向正弦
ScanlineShader : sin(_x0009.y) 计算y方向正弦
ScanlineShader : dot(_a0015, vec2(1.0, 1.0)) 计算调制强度
ScanlineShader : _TMP0.xyz*(0.95 + _TMP2) 应用扫描线效果
```

#### retro-v2着色器
该着色器实现复杂的色彩校正和对比度增强效果。

```mermaid
sequenceDiagram
participant Fragment as "片段着色器"
participant Texture as "纹理采样"
participant Gamma as "伽马校正"
participant Interpolation as "插值计算"
participant Output as "最终输出"
Fragment->>Texture : COMPAT_TEXTURE(Texture, TEX0.xy)
Texture-->>Fragment : 获取原始颜色_TMP0
Fragment->>Gamma : pow(_TMP0.xyz, 2.4) 输入伽马校正
Gamma-->>Fragment : 线性空间颜色_E
Fragment->>Interpolation : 计算像素位置和插值权重
Interpolation-->>Fragment : 插值因子_f和_max_coord
Fragment->>Interpolation : 计算加权颜色_a0040和_b0040
Interpolation-->>Fragment : 混合结果_res
Fragment->>Gamma : pow(_res.xyz, 0.4545) 输出伽马校正
Gamma-->>Output : 最终颜色_OUT._color
```

## 性能考虑

### 着色器链性能影响

| 着色器数量 | 性能影响 | 适用场景 |
|-----------|---------|---------|
| 0-1个 | 低 | 基本显示 |
| 2-3个 | 中等 | 常规增强 |
| 4个以上 | 高 | 高级视觉效果 |
