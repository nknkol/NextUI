## 简介
本文档详细记录了NextUI提供的各类工具与实用程序，包括电池监控、时钟设置、LED灯效控制、系统配置、蓝牙管理以及新添加的合成器工具。这些工具作为独立应用或插件集成在主菜单中，通过shell脚本或插件系统启动，为用户提供直观的交互界面和灵活的配置选项。文档将深入分析每个工具的功能实现、用户交互方式、配置机制以及开发者如何创建新工具。特别关注gametime功能从独立工具到插件系统的迁移过程，以及新添加的蓝牙设置工具。

## 项目结构
NextUI的工具模块采用清晰的分层结构，分为源码实现、编译配置和运行时包三个层级。源码位于`workspace/tools/`目录下，每个工具拥有独立的C/C++实现文件和Makefile；编译后的可执行文件被打包为`.pak`格式，存放在`skeleton/EXTRAS/Tools/`目录中，通过`launch.sh`脚本启动。值得注意的是，gametime功能已从`workspace/tools/gametime`迁移至`workspace/plugins/gametime`，作为动态加载的插件运行，不再通过`.pak`包分发。**新添加的蓝牙设置工具`Settingsbt.pak`位于`skeleton/EXTRAS/Tools/`目录下，其源码位于`workspace/tools/settingsbt/`，使用C++编写，通过`launch.sh`脚本启动。**

## 核心组件
NextUI的工具系统由六个核心实用程序构成：电池监控（Battery）、时钟设置（Clock）、LED控制（LedControl）、系统设置（Settings）、蓝牙设置（Settingsbt）和新添加的合成器（Compositor）。此外，gametime功能已重构为插件，通过插件系统动态加载。这些工具共享一套基础库（libcommon），包括API接口、配置管理、语言支持和平台抽象层，确保了代码的可维护性和跨平台兼容性。**蓝牙设置工具（Settingsbt）是一个新添加的组件，专门用于管理蓝牙设备的连接、配对和诊断。**

## 架构概述
整个工具系统采用模块化架构，每个工具作为独立进程运行，通过调用`libcommon`库与系统进行交互。系统设置工具（Settings）作为中心配置枢纽，管理WiFi、显示、语言等全局偏好，而其他工具则专注于特定功能。gametime功能作为插件，通过插件系统在运行时动态加载，与主菜单集成。**蓝牙设置工具（Settingsbt）通过`libcommon`库中的蓝牙API与系统蓝牙守护进程（bt_daemon）交互，实现对蓝牙设备的发现、配对、连接和断开操作。**

```c
void secondsToHoursMinutes(int seconds, char *output) {

    sprintf(output, "%dh%02d", hours, minutes);
}
```
该函数将秒数转换为“XhYY”格式的时间字符串，用于显示会话时长和剩余时间。

### 合成器工具分析
合成器工具是一个新的系统级工具，通过DRM（Direct Rendering Manager）API直接控制显示输出，实现了高级的图形合成功能。

#### 功能实现
```c
// 从compositor.c中提取的关键代码
int main() {
    // 1. 打开 DRM 设备
    fd = open("/dev/dri/card0", O_RDWR | O_CLOEXEC);
    
    // 2. 获取 DRM 资源
    resources = drmModeGetResources(fd);
    
    // 3. 查找已连接的显示设备
    for (i = 0; i < resources->count_connectors; i++) {
        connector = drmModeGetConnector(fd, resources->connectors[i]);
        if (connector->connection == DRM_MODE_CONNECTED) {
            break;
        }
        drmModeFreeConnector(connector);
        connector = NULL;
    }
    
    // 4. 创建帧缓冲区并设置显示模式
    drmModeSetCrtc(fd, crtc->crtc_id, fb_id, 0, 0, &connector->connector_id, 1, mode);
    
    // 5. 清理资源
    cleanup();
    close(fd);
    return 0;
}
```
该代码展示了合成器工具的核心工作流程：打开DRM设备、获取显示资源、创建帧缓冲区、设置显示模式和清理资源。

蓝牙设置工具（Settingsbt）是一个新添加的系统级工具，用于管理设备的蓝牙功能，包括设备发现、配对、连接和诊断。它通过`libcommon`库中的蓝牙API与底层`bt_daemon`守护进程交互。

#### 用户交互流程
蓝牙设置工具的用户交互流程如下：
1.  **启动**: 工具启动后，初始化SDL和输入系统，并调用`BT_init`初始化蓝牙上下文。
2.  **主菜单**: 显示一个包含“Bluetooth”、“Bluetooth diagnostics”和“Maximum sampling rate”选项的主菜单。
3.  **后台更新**: 一个独立的`updater`线程每15秒执行一次扫描：
    *   调用`BT_discovery(true)`开启设备发现。
    *   调用`BT_availableDevices`获取可发现的设备列表。
    *   调用`BT_pairedDevices`获取已配对的设备列表。
    *   动态更新主菜单，将可发现的设备和已配对的设备作为子菜单项添加。
4.  **设备管理**: 用户可以选择一个设备，进入其子菜单进行操作：
    *   **可发现设备**: 可以选择“Pair”进行配对。
    *   **已配对设备**: 如果未连接，可以“Connect”；如果已连接，可以“Disconnect”；在任何情况下都可以“Unpair”取消配对。
5.  **设置更改**: 用户可以直接在主菜单中切换蓝牙开关或诊断日志开关，这些操作会立即调用`BT_enable`或`BT_diagnosticsEnable`等API。

## 性能考虑
所有工具在启动时调用`PWR_setCPUSpeed(CPU_SPEED_MENU)`将CPU频率设置为菜单模式，平衡了性能和功耗。该函数通过`PLAT_setCPUSpeed`实现，根据系统平台调整CPU性能策略。图形渲染使用SDL库进行硬件加速，确保界面流畅。合成器工具直接使用DRM API进行显示控制，避免了中间层的开销，提供了更高的性能和更低的延迟。日志记录通过`LOG_note`函数实现，支持实时日志输出到文件，便于调试。

## 故障排除指南
- **工具无法启动**：检查`launch.sh`脚本中的可执行文件名是否与编译输出一致。
- **设置不保存**：确认`SHARED_USERDATA_PATH`环境变量是否正确指向可写目录。
- **LED无反应**：检查设备是否具有`/sys/class/led_anim/`接口，并确认权限设置。
- **合成器工具失败**：确认系统是否安装了`libdrm-dev`库，并检查`/dev/dri/card0`设备是否存在。
- **游戏时间插件不显示**：确认`PLUGIN_PATH`目录下存在`gametime.so`文件，并检查插件加载日志。
- **蓝牙设置工具无设备列表**：确认`bt_daemon`进程正在运行，并检查`settings.log`日志文件中的错误信息。
